# Bridge Part 3: vanishing gauge invariants ⟹ pure gauge (modes with ω ≠ 0)

The planned route was "linearised Plebański–Demiański rigidity". It is **replaced** by a shorter argument via a linearised Killing field, which needs no classification of type-D solutions.

## Setting

A linearised Einstein–Maxwell solution (h, δF) on Kerr–Newman with time dependence e^{-iωt}, ω ≠ 0, Im ω ≥ 0. From Parts 1–2 and the dictionary:

  A = A̲ = 0,  B = B̲ = 0,  F = F̲ = 0,  X = X̲ = 0.

## Step 1: phantom gauge ⟹ the perturbation stays type D with an aligned Maxwell field

The background has φ₁ ≠ 0, so an infinitesimal null rotation can set δφ₀ = δφ₂ = 0. This is Chandrasekhar's phantom gauge, available because φ₀ → φ₀ + 2c̄φ₁ under such a rotation. In this gauge, Giorgi's Remark 5.5 (with conjugation bars restored) gives:

- B = 3φ₀Ψ₂ − 2φ₁Ψ₁ = 0 ⟹ δΨ₁ = 0, and likewise B̲ = 0 ⟹ δΨ₃ = 0.
- F = −δφ₀ + … − 2σφ₁ = 0 ⟹ δσ = 0, and likewise δλ = 0.
- X = Dφ₀ − … + 2κφ₁ = 0 ⟹ δκ = 0, and likewise δν = 0.
- A = A̲ = 0 ⟹ δΨ₀ = δΨ₄ = 0.

So, to first order, both principal null directions remain geodesic and shear-free, the Weyl tensor remains type D, and the Maxwell field remains aligned with the principal null directions.

## Step 2: a linearised Killing field

For type-D Einstein–Maxwell solutions with aligned non-null Maxwell field (a class that contains Kerr–Newman):

- there is a Killing spinor κ_AB = Ψ₂^{-1/3} o_(A ι_B), up to normalisation;
- ξ^{AA'} = ∇^{A'}_B κ^{AB} is a Killing vector. For Kerr–Newman it is ∂_t, up to a constant.

Both facts are derived from the GHP/NP field equations **using only** the type-D and alignment conditions together with the Einstein–Maxwell equations. Each step of that derivation is a differential identity. Linearising it about Kerr–Newman therefore gives:

  κ + εκ′ satisfies the Killing spinor equation to O(ε²), and ξ + εξ′ satisfies the Killing equation to O(ε²):
  L_ξ h + L_{ξ′} g = 0,  L_ξ δF + L_{ξ′} F = 0.

Here ξ′ is built explicitly from (h, δΨ₂, the perturbed tetrad), so it is smooth wherever h is. Note Ψ₂ ≠ 0 on the exterior, so Ψ₂^{-1/3} is smooth.

## Step 3: ω ≠ 0 forces pure gauge

Work in the gauge where ξ = ∂_t. Then L_ξ h = −iω h, so

  h = (1/(iω)) L_{ξ′} g,  δF = (1/(iω)) L_{ξ′} F.

So (h, δF) is a pure linearised diffeomorphism, generated by V = ξ′/(iω), plus possibly an electromagnetic gauge term at the level of the potential. ∎

## Open items

- **(P3a)** Cite or prove the electrovac Killing-spinor facts precisely for the type-D aligned class: existence of κ_AB, and the Killing property of ∇κ. Then check that every step of the derivation is a field-equation identity, so that it linearises. Candidate sources: Walker–Penrose (vacuum); Hughston, Penrose, Sommers and Walker; Andersson–Bäckdahl–Blue (Killing spinors on Kerr–Newman).
- **(P3b)** Regularity and decay of V = ξ′/(iω) at H⁺ and I⁺, in the function spaces Hintz uses. It is built from smooth curvature and frame quantities of a regular outgoing mode, but the weights must be checked.
- **(P3c)** The phantom gauge rotation must itself be regular. Its parameter is c = −δφ₀/(2φ̄₁), and φ₁ ≠ 0 on the exterior, so it is smooth.
- **(P3d)** The ω = 0 case is not covered here. That is item A11 (stationary perturbations): linearised uniqueness giving δM, δa, δQ, δP plus gauge.
