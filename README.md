# Stability of Kerr–de Sitter black holes in the full subextremal range

Jaideep Sai Padhi (Purdue University)

This repository contains the manuscript

> **Gravitational mode stability and the nonlinear stability of Kerr–de Sitter black holes in the full subextremal range**

and the code for its computer-assisted steps.

Preprint (v1): Zenodo, [doi:10.5281/zenodo.24146364](https://doi.org/10.5281/zenodo.24146364).

## Results

- **Theorem A.** The Teukolsky equations of spin ±2 on every subextremal Kerr–de Sitter spacetime have no nontrivial
  outgoing (generalized) mode solutions with Im σ ≥ 0.
- **Theorem B.** Every generalized mode of the ungauged linearized Einstein equation with Im σ ≥ 0 is pure gauge, up to
  a linearized Kerr–de Sitter metric when σ = 0. This is Assumption 1.2 of Hintz–Petersen–Vasy
  ([arXiv:2508.06620](https://arxiv.org/abs/2508.06620)).
- **Theorem C.** Combined with Hintz–Petersen–Vasy, Theorem 1.4: subextremal Kerr–de Sitter black holes are
  nonlinearly stable in the full subextremal range.

## Arithmetic

Except for C9, all checks are exact, over ℚ or ℚ(i), using `sympy` and `python-flint`.

C9 works as follows:
- Bernstein coefficients are computed exactly and rounded once to double precision.
- The arrays are subdivided by de Casteljau, carrying an entrywise a-priori error bound alongside each array
  (`fsign2` in `cert3/fbern2.py` and `cert3/fbern3.py`).
- The physical root b₊ is enclosed with `mpmath` interval arithmetic.

The paper's Appendix A, item C9, states the error bound.

## Requirements

Python ≥ 3.10, `sympy`, `python-flint`, `numpy`, `mpmath`.

Builders write intermediate pickles to `certificates/cert3/margin/`. These are not tracked: they are regenerated by the
`*_build.py` scripts. Some C9 runs take several minutes, and `atlas.sh` drives the chart-by-chart coverings.
